# خطوة

منصة متابعة مقررات المرحلة المتوسطة. الطالب يدخل برمز من ٤ أرقام فيشوف مقررات اليوم والأسبوع،
ويسجّل ما سمعه وما قرأه. المشرف يضيف المقررات ويتابع صفه. المشرف التنفيذي يتابع الجميع ويضيف الحسابات.

## التشغيل محليًا

```bash
npm install
cp .env.example .env.local   # واملأ القيم من لوحة Supabase
npm run dev
```

القيم تجيبها من: Supabase → Project Settings → API
- `VITE_SUPABASE_URL` = Project URL
- `VITE_SUPABASE_KEY` = المفتاح العام (publishable / anon)

> لا تضع مفتاح `service_role` هنا إطلاقًا. المفتاح العام آمن للنشر لأن قاعدة البيانات مقفلة بالكامل.

## النشر على Vercel

1. ارفع المستودع على GitHub.
2. في Vercel: New Project → اختر المستودع.
3. Framework: **Vite** (يُكتشف تلقائيًا). Build: `npm run build`. Output: `dist`.
4. أضف المتغيرين `VITE_SUPABASE_URL` و `VITE_SUPABASE_KEY` في Environment Variables.
5. Deploy.

## قاعدة البيانات

الهجرات في `supabase/migrations/`. لو أنشأت مشروع Supabase جديدًا، شغّلها بالترتيب
(من محرر SQL في لوحة Supabase، أو عبر `supabase db push`).

### الجداول
| الجدول | الوظيفة |
|---|---|
| `accounts` | الطلاب والمشرفون والتنفيذي في جدول واحد — يضمن أن الرمز فريد عبر الجميع |
| `assignments` | المقررات: نوعها (`audio` بالدقائق / `book` بالصفحات)، مقدارها، تاريخ تسليمها |
| `progress` | إنجاز الطالب لكل مقرر (قيد فريد يمنع الاحتساب مرتين) |
| `sessions` | الجلسات، صلاحيتها ٣٠ يومًا |
| `login_attempts` | لتحديد عدد المحاولات |

### الأمان
كل الجداول عليها RLS **بلا أي سياسة**، أي أن المتصفح لا يقرأ منها ولا يكتب فيها مباشرة إطلاقًا.
كل الوصول يمر عبر دوال `security definer` تتحقق من الجلسة والدور قبل تنفيذ أي عملية:

| الدالة | لمن |
|---|---|
| `login`, `whoami`, `logout` | الجميع |
| `student_board`, `mark_done`, `unmark_done` | الطالب فقط |
| `supervisor_board`, `save_assignment`, `delete_assignment` | المشرف فقط |
| `exec_board`, `create_account`, `deactivate_account` | التنفيذي فقط |

قيود مفروضة على مستوى القاعدة نفسها (لا يمكن الالتفاف عليها من الواجهة):
- مشرف واحد لكل صف.
- الطالب لا يسجّل صفحات أكثر من صفحات المقرر (يُقصّ تلقائيًا).
- المقرر لا يُحتسب مرتين لنفس الطالب.
- المشرف يعدّل ويحذف مقررات صفه فقط.

### حد المحاولات
٧ محاولات فاشلة لكل جهاز خلال ١٥ دقيقة، و٤٠ محاولة فاشلة على مستوى النظام خلال ٥ دقائق.

> **ملاحظة مهمة:** الرمز ٤ أرقام = ١٠٬٠٠٠ احتمال. حدّ المحاولات يمنع التجريب الآلي،
> لكن ابقَ منتبهًا: لا توزّع الرموز بالتسلسل، ووزّعها فرديًا لا في قائمة يشوفها الجميع.

## الحسابات الأولية

| الدور | الرمز |
|---|---|
| المشرف التنفيذي | `1000` |
| مشرف أول متوسط | `1101` |
| مشرف ثاني متوسط | `1102` |
| مشرف ثالث متوسط | `1103` |

**بدّل رمز التنفيذي `1000` قبل الاستخدام الحقيقي** — سهل التخمين:

```sql
update accounts set code = '____' where role = 'exec';
```
